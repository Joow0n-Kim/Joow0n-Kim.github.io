# joow0n-kim.github.io

Personal academic website of Joowon Kim, built with [Astrofy](https://github.com/manuelernestog/astrofy) (Astro + Tailwind + DaisyUI).

- Content lives in `src/data/` (`publications.ts`, `news.ts`, `cv.ts`) and `src/config.ts`.
- Local dev: `pnpm install && pnpm dev`; build: `pnpm build`.
- Pushing to `main` deploys via GitHub Actions (Settings → Pages → Source: GitHub Actions).
